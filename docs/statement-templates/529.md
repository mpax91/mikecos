# Statement template: `529` → `ny529`

Code: `worker/src/statements/templates/ny529.ts` (parser + cross-checks),
`ny529Summary.ts` (dashboard/deduction math), `ny529Derive.ts` (Vault note,
flags, reminders, Tax Packet).

- **Account:** NY 529 Direct Plan, Individual 529, owner Michael, beneficiary
  Chase (Owner dimension: Chase). Acct stored as last digits only (`2087-01`).
- **Files:** `529 - YYYY.MM.DD.pdf`, quarterly, text-based (pdf.js via `unpdf`).
- **Layout eras:** one (2026 Q1 →).

## Fields
| Field | Located by |
|---|---|
| Period | `Statement Period: M/D/YYYY - M/D/YYYY` |
| Beginning / Change / Ending / Principal / Earnings | line label + `$` amount |
| Quarter + YTD contributions | `Current Year Contributions - All Sources $q $ytd` |
| Holdings | rows between `INVESTMENT SUMMARY` and `Total:` (name, units, price, value) |
| Transactions | `MM/DD/YYYY <desc>` line … `<units> $<price> $<amount>` line, until `DISCLOSURES` |

Transaction kinds: `AIP` → aip; contribution/deposit → contribution;
withdrawal/distribution or negative → withdrawal.

## Checks
In-statement: Beginning + Change = Ending; Principal + Earnings = Ending;
Holdings total = Ending; Units × Price ≈ Value; contribution transactions =
quarter contributions. Between statements: prior Ending = Beginning; YTD chain.
